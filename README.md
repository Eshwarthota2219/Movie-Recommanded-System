# Movie Recommender System (Content-Based Filtering)

![](https://github.com/Eshwarthota2219/Movie-Recommanded-System/blob/main/download.jpg)

🎬 Project Overview
This Movie Recommender System is a content-based filtering application designed to suggest relevant movies to a user based on their input. The application analyzes movie metadata (such as genre, keywords, cast, and director) to calculate similarity and recommend the 5 closest matching films.

A key feature of this application is its ability to direct the user to a specific download page when they click on a recommended movie, enhancing the practical utility of the system.

🚀 Live Deployment
Access the live application here:  ![](https://movie-recommanded-system-mdznazjo4pffjjgaatwc8m.streamlit.app/)

✨ Features
Intelligent Recommendations: Uses content-based filtering (e.g., TF-IDF or vector space modeling) to find movies highly similar to the user's selected choice.

Top 5 Suggestions: Provides a curated list of the 5 most similar movies.

Direct Download Link: Upon clicking any suggested movie, the user is redirected to the movie's external download page or resource link (configured within the application logic).

User-Friendly Interface: Built using Streamlit for a simple and interactive web experience.

Data Serialization: Efficiently loads pre-calculated movie data and similarity matrix using Python's pickle library for fast retrieval.

💻 Getting Started (Local Setup)
Follow these instructions to set up and run the project locally.

Prerequisites
You will need the following installed:

Python (3.7+)

pip (Python package installer)

Installation
Clone the repository:

git clone [https://github.com/YourUsername/movie-recommender-system.git](https://github.com/YourUsername/movie-recommender-system.git)
cd movie-recommender-system

Install dependencies:
(Ensure you install streamlit as well)

pip install pandas numpy scikit-learn streamlit

Running the Application Locally
Run the analysis script (Initial Setup):
If the movie_list.pkl and similarity.pkl files are not present, you must run your main processing notebook/script (Moive-Recommender-System.ipynb or a corresponding Python file) to generate them.

# Open the notebook and run all cells to generate .pkl files
jupyter notebook Moive-Recommender-System.ipynb

Start the Streamlit application:
(Assuming your main application file is named app.py)

streamlit run app.py

Access the App:
Open your web browser and navigate to the local address provided by Streamlit (usually http://localhost:8501).
